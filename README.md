# NeuroNexus
🚢 Titanic Survival Prediction - Machine Learning Project

This project predicts whether a passenger survived the Titanic disaster using machine learning models trained on passenger data such as age, gender, ticket class, fare, and more.

### 📁 Dataset

This project uses the **Titanic dataset** from [Kaggle](https://www.kaggle.com/c/titanic) that includes:

* Passenger details (Age, Sex, Fare, Embarked, etc.)
* Survival status (target)

You can use `tested.csv` or any compatible Titanic dataset in `.csv` format.

### ⚙️ Features Used

 Feature     Description                   
 
 Pclass      Ticket class (1st, 2nd, 3rd)  
 Sex         Gender                        
 Age         Age of the passenger          
 SibSp       # of siblings/spouses aboard  
 Parch       # of parents/children aboard  
 Fare        Fare paid for the ticket      
 Embarked    Port of Embarkation (C, Q, S) 


### Models Implemented

✅ Logistic Regression
✅ Random Forest Classifier
✅ Support Vector Machine (SVM)


### Evaluation Metrics

* Accuracy
* Precision, Recall, F1-score
* Confusion Matrix
* Bar chart comparing model performance

* Printed model accuracy
